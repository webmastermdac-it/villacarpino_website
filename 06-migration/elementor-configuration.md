# Configurazione WordPress/Elementor

- Identificare versioni WordPress, Elementor, Pro, Theme Builder, tema, plugin SEO e form.
- Impostare colori e spaziature da `03-elementor/elementor-design-system.json`.
- Impostare Global Fonts come `03-elementor/elementor-global-typography.json`. Solo Playfair Display e DM Sans.
- Configurare header/footer globali: menu desktop sempre visibile, fondo opaco, nessuna prenotazione nell’header.
- Ricostruire le pagine con container e widget nativi. Non incollare l’intera pagina in HTML widget.
- Adeguare le media query e i breakpoint secondo `03-elementor/elementor-responsive.md`.
- Configurare form, consenso, SMTP/deliverability e anti-spam.
- Verificare su staging prima di pubblicare.
