# Dipendenze e limiti

- HTML: CSS e JavaScript locali; Google Fonts Playfair Display/DM Sans TTF locali.
- `contatti.html`: iframe e link Google Maps richiedono accesso rete e trattamento privacy.
- Form contatti: demo front-end, non invia email. Richiede integrazione WordPress.
- Il menu mobile HTML usa `details` nativo, senza plugin.
- Elementor Pro/Theme Builder e widget form vanno verificati nella reale installazione.
- Immagini: enhancement deterministico con Pillow; nessun upscaling o editing generativo.
- Il pacchetto non contiene credenziali o connettori MCP.
